# Mixtape de Aniversário

Uma página de aniversário inspirada na ideia de uma mixtape digital.

## Estrutura

- `index.html` — estrutura da página
- `style.css` — visual
- `script.js` — player e interações
- `assets/` — coloque suas fotos e músicas

## Personalização

No `index.html`, troque:

- `[NOME]`
- `[SEU NOME]`
- textos das memórias
- `assets/foto1.jpg`

No `script.js`, troque os nomes dos artistas, títulos e arquivos das músicas.

Coloque:

- `foto1.jpg`
- `musica1.mp3`
- `musica2.mp3`
- `musica3.mp3`
- `musica4.mp3`
- `musica5.mp3`
- `musica6.mp3`

na pasta `assets`.

## Rodar localmente

Dentro da pasta:

```bash
python3 -m http.server 8000
```

Abra:

http://localhost:8000
